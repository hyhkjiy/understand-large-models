第一课

多头注意力:不止一双眼睛

multi-head attention

第一册第五课的 Attention 是"一双眼睛":一套 Q/K/V,一种看法。真实模型里,每层有几十套 Q/K/V 并行地各看各的——有的头盯指代关系,有的头盯邻居,有的头盯语法搭配。这就是"多头"。

lesson1_multihead.py
import math

def softmax(xs):
    ex = [math.exp(x) for x in xs]; s = sum(ex)
    return [e / s for e in ex]

words = ["小猫", "追", "老鼠", "因为", "它", "饿"]
# 同一个「它」,两个头各有一套 K(来自不同的参数矩阵 W_K)
K_headA = [[1.8,0.6],[0.2,0.1],[0.9,-0.5],[0.1,0.2],[0.5,1.0],[0.4,0.3]]   # 指代头
K_headB = [[0.1,0.2],[0.3,0.1],[0.2,0.3],[1.5,0.8],[0.6,0.4],[1.6,0.7]]   # 语境头
q = [2.0, 0.4]                                 # 「它」的查询向量

for name, K in [("头A(指代)", K_headA), ("头B(语境)", K_headB)]:
    w = softmax([(q[0]*k[0] + q[1]*k[1]) / math.sqrt(2) for k in K])
    top = words[w.index(max(w))]
    print(name, " ".join(f"{x}:{p:.0%}" for x, p in zip(words, w)), "→ 最关注:", top)
# 同一个 q,不同的 K 参数 → 完全不同的关注点。拼接后两种信息都保留。

第二课
前馈网络 FFN:真正的"隐藏层"来了
feed-forward network

  
这就是你在别处听说的"神经网络隐藏层"。结构简单到失望:放大 → 掰弯 → 压回。但"掰弯"那一下,是整个深度学习的魔法所在。


  

    问 题
    
只用加法和乘法,能表达"猫饿了就找吃的,但吃饱了就睡觉"吗?

    
不能。加法乘法只能画直线(线性关系):输入变大,输出等比例变化,永远直来直去。而知识充满"拐弯":条件、分段、饱和。需要一个能拐弯的零件。

lesson2_ffn.py

      
relu = lambda v: max(0.0, v)

def ffn(x, bend=True):                         # 两个神经元的迷你 FFN
    g = relu if bend else (lambda v: v)        # bend=False 就是"去掉掰弯器"
    h1, h2 = g(x - 1), g(x - 3)
    return h1 - 2 * h2

print("x     有ReLU   没ReLU")
for x in [0, 1, 2, 3, 4, 5]:
    print(f"{x}      {ffn(x):5.1f}   {ffn(x, bend=False):5.1f}")
# 有 ReLU:0 0 1 2 1 0 —— 一座山(非线性!)
# 没 ReLU:(x-1)-2(x-3) = -x+5 —— 永远是直线。
# 没有激活函数,叠 100 层也只是直线套直线 = 还是直线。

一层 = 多头 Attention + FFN。GPT-3 堆了 96 层。但直接往上摞会出事:每层都对信号做一次变换,几十层下来,信号要么衰减到消失、要么放大到爆炸——训练信号(梯度)同样过不去。深楼时代之前,"超过十几层就训不动"困扰了整个领域好几年。









  
第三课
残差连接:给每一层修一条"高速直通道"
residual & layernorm

  
解决方案是一个加号:每层的输出不是 F(x),而是 x + F(x)——把输入原封不动抄一份加回来。层只需要学"该修改什么"(残差),不必学"如何复述一切"。


  

    动手玩
    
拖层数,看信号在两种楼里的命运

    

      
4

      

        

          
没有残差:每层信号 ×0.9(轻微衰减)

          

          

        

        

          
有残差 + LayerNorm:x + F(x),再拉回标准体型

          

          

        

      

      

    

  


  

    公 式
    
一个加号,一次"整队"

    

      

        输出=LayerNorm(x+F(x))
      

      
把鼠标移到公式的某一项上试试 →

      
对训练同样致命的是反方向:第一册第三课的梯度要从 loss 一路传回第 1 层。没有直通道,梯度逐层乘小数,传到底就没了(梯度消失)。有了 x + F(x),梯度沿加号那条路原样直达——几百层照训不误。2015 年 ResNet 靠这一个加号把可训练深度从 20 层推到 1000 层。

    

  


  

    回到大模型

  串联桥 · 第三课 → 第四课
  
楼盖好了——但第一册欠的最后一笔账该还了

  
第一册第三课说:"对几百亿个参数各自求坡度(反向传播干的活)"。当时一笔带过。现在楼里每个参数——96 层里的每个 W、每个 embedding——都需要自己的 ∇L。挨个"挪一挪试试"要算几百亿次前向,宇宙热寂都等不来。反向传播,就是那个把这件事变成"一次扫描全搞定"的算法。









  
第四课
反向传播:坡度沿着链条往回乘
backpropagation

  
核心只有一条小学奥数式的规则——链式法则:A 影响 B、B 影响 L,那么"A 对 L 的影响" = 两段影响相乘。网络再深,也只是把沿路的"局部坡度"一路乘回去。


  

    动手玩
    
一条四节小链,亲眼看坡度怎么"往回流"

↓ 反向:每节的"局部坡度"连乘,就是 w₁ 的梯度

      

      

      

    

  


  

    公 式
    
链式法则:影响力 = 沿路坡度的连乘

    

      

        dLdw1=​dLdŷ·dŷdh·dhda·dadw1
      

      
把鼠标移到公式的某一项上试试 →

      
"反向传播"= 链式法则的流水线化:先前向算一遍存下沿路数值,再从 loss 出发倒着扫一遍,每个参数顺手拿到自己的梯度。总代价 ≈ 两次前向——几百亿参数也只要一个来回,这就是第一册第三课"对每个参数求坡度"四个字背后的全部秘密。第一册那个漂亮的闭式梯度 p − 1,正是这条链最末两节(softmax+交叉熵)乘出来的结果。

    

  


  

    手算验证
    
四个数,乘一遍

    

      设某时刻链上四段坡度分别是:dL/dŷ = 2,dŷ/dh = 0.5,dh/da = 1,da/dw₁ = 3:

      dL/dw₁ = 2 × 0.5 × 1 × 3 = 3.0 —— 意思是:w₁ 挪 0.01,L 大约动 0.03。
      
✍️ 轮到你:若四段坡度是 1.5、2、1、1,dL/dw₁ = ?

import math

w1, w2, x, y = 0.8, -1.2, 1.5, 1.0
a = w1 * x                                     # 前向:一节节算过去,存下沿路数值
h = math.tanh(a)
yh = w2 * h
L = (yh - y) ** 2
print(f"前向: a={a:.3f}  h={h:.3f}  ŷ={yh:.3f}  L={L:.3f}")

g = 2 * (yh - y)                               # 反向:从 L 出发,坡度一路往回乘
g_h  = g * w2                                  #   × dŷ/dh

g_w1 = g_a * x                                 #   × da/dw₁ —— w₁ 的梯度到手
print("链式法则算出 dL/dw1 =", round(g_w1, 6))

给第一册的玩具模型,真的装上隐藏层

第一册的彩蛋是一张查表(没有隐藏层)。现在升级:embedding(第二册)→ tanh 隐藏层(本册第二课)→ 打分,梯度全程手写反向传播(本册第四课)穿过每一层——没有任何框架,没有任何黑盒。对照注释找每个零件的出处。

  

    
train_toy_llm_v2.py

    
import math, random
random.seed(0)

# ── 语料与词表:和第一册终极彩蛋完全相同 ─────────────────
corpus = "今天 天气 很 好 。 今天 天气 很 冷 。 明天 天气 很 好 。 今天 心情 很 好 。".split()
vocab = sorted(set(corpus)); n = len(vocab)
idx = {w: i for i, w in enumerate(vocab)}

D = 4                                          # 隐藏层宽度(真实模型:几千)
rnd = lambda: random.uniform(-0.5, 0.5)
E  = [[rnd() for _ in range(D)] for _ in range(n)]   # 词向量表(第二册)
W1 = [[rnd() for _ in range(D)] for _ in range(D)]   # 隐藏层(本册第二课)
W2 = [[rnd() for _ in range(n)] for _ in range(D)]   # 打分层(第一册第一课)

def softmax(z):
    m = max(z); ex = [math.exp(v - m) for v in z]; s = sum(ex)
    return [e / s for e in ex]

def forward(w):                                # 前向:查表 → 掰弯 → 打分
    x = E[idx[w]]
    h = [math.tanh(sum(x[i]*W1[i][j] for i in range(D))) for j in range(D)]
    z = [sum(h[i]*W2[i][j] for i in range(D)) for j in range(n)]
    return x, h, z, softmax(z)

pairs = list(zip(corpus[:-1], corpus[1:]))
lr = 0.1
for epoch in range(240):
    loss = 0.0
    for prev, nxt in pairs:
        x, h, z, p = forward(prev)
        loss += -math.log(p[idx[nxt]])                            # 交叉熵(第一册)
        dz = [p[j] - (1 if j == idx[nxt] else 0) for j in range(n)]   # 闭式梯度 p−y
        dh = [sum(dz[j]*W2[i][j] for j in range(n)) for i in range(D)]  # ↓反向传播
        dt = [dh[i]*(1 - h[i]**2) for i in range(D)]              # 穿过 tanh(链式法则!)
        dx = [sum(dt[j]*W1[i][j] for j in range(D)) for i in range(D)]
        for i in range(D):                                        # 梯度下降(第一册)
            for j in range(n): W2[i][j] -= lr * h[i] * dz[j]
            for j in range(D): W1[i][j] -= lr * x[i] * dt[j]
            E[idx[prev]][i] -= lr * dx[i]                         # embedding 也在学!
    if epoch % 60 == 0 or epoch == 239:
        print(f"第{epoch:3d}轮   平均罚分 = {loss/len(pairs):.3f}")

w = "今天"; sent = [w]                          # 推理:接龙(第一册第四课)
for _ in range(4):
    _, _, _, p = forward(w)
    w = max(vocab, key=lambda t: p[idx[t]]); sent.append(w)
print("模型接龙:", " ".join(sent))

    

  

  
跑通之后的三个实验:① 把 D 改成 1(隐藏层瘦成一根针),罚分还降得下去吗?② 把 math.tanh 换成 lambda v: v(去掉掰弯器),对比最终罚分——第二课的预言当场应验;③ 数一数参数总量(E + W1 + W2),对比第一册彩蛋那张 n×n 的表。从这份代码到 GPT,只差三件事:把隐藏层换成 96 层「Attention+FFN+残差」、把语料换成半个互联网、把 for 循环搬到几万块 GPU 上。

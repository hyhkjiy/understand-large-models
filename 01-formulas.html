第一课
Softmax:把分数变成概率
softmax

  
大模型说话前,内心其实是在给每个候选词打分。但"打分"没法直接用——我们需要把分数变成"可能性"。


  

    问 题
    
模型看到「今天天气很 ___」,该接哪个词?

    
模型内部会给词表里每个词打一个分数(叫 logit),分数可正可负,加起来也不等于任何固定值。比如「好」得 2.0 分,「冷」得 0.5 分,「糟」得 −1.0 分。分数高说明模型更倾向这个词——但"2.0 分"到底是多大的把握?我们需要把它翻译成百分比。

    
那分数本身又是从哪来的?(可先跳过,第五课会闭环回来)
      
每个词的分数 = 上下文向量 · 该词的输出权重(就是一次点积)。用第五课将会算出的融合向量 h = (1.17, 0.39):

      
候选词输出权重 W点积 h·W分数 z

      
好(1.5, 0.62)1.17×1.5 + 0.39×0.62≈ 2.0

      
冷(0.2, 0.68)1.17×0.2 + 0.39×0.68≈ 0.5

      
糟(−1.0, 0.44)1.17×(−1.0) + 0.39×0.44≈ −1.0

      
对,滑块的三个默认值就是这么来的——本页所有数字是同一个故事。

    公 式
    
你刚才玩的东西,写下来就是它

    
规则其实只有两条:① 给每个分数取指数 ez(保证结果是正数,且分数越高放大越狠);② 除以所有指数之和(保证加起来恰好是 1)。鼠标放到公式的任何部分上,对应的东西会亮起来:

    

      

        p(词i)=eziΣj ezj
      

      
把鼠标移到公式的某一项上试试 →

      
带温度的版本只是先把分数除以 T 再照做:pi = ezi/T / Σj ezj/T。T 越小,差距被放得越大,分布越"极端";T 越大越"平均"。这就是你在别处听到的"温度采样"。

    

  


  

    手算验证
    
用一个能口算(几乎)的例子核对

    

      分数 z = (2.0, 0.5, −1.0),T=1:

      e2.0 ≈ 7.39    e0.5 ≈ 1.65    e−1.0 ≈ 0.37   →  和 ≈ 9.41

      p(好) = 7.39 / 9.41 ≈ 0.79    p(冷) ≈ 0.18    p(糟) ≈ 0.04

      回到上面的滑块,把数值调回 2.0 / 0.5 / −1.0,看看柱子是不是正好这三个数。公式没有骗你。

    回到大模型
    
GPT 每生成一个字之前,都对词表里的几万到十几万个词做一次你刚才做的事:打分 → softmax → 得到一整排概率,再从中挑一个词。你调的"温度"参数,就是 ChatGPT 接口里那个真实的 temperature。

  

  

    🐍 用 Python 验证这一课(可选:一键复制,或直接在页内运行)
    

      
lesson1_softmax.py

      
import math

def softmax(scores, T=1.0):
    ex = [math.exp(z / T) for z in scores]     # ① 取指数:全变正数
    total = sum(ex)
    return [e / total for e in ex]             # ② 除以总和:加起来=1

scores = [2.0, 0.5, -1.0]                      # 好 / 冷 / 糟
for word, p in zip("好冷糟", softmax(scores)):
    print(word, round(p, 2))                   # 应得 0.79 / 0.18 / 0.04

print("低温 T=0.2:", [round(p,2) for p in softmax(scores, T=0.2)])
print("高温 T=5.0:", [round(p,2) for p in softmax(scores, T=5.0)])

第二课
交叉熵:给预测打分的裁判
cross-entropy

  
模型给出了概率,那怎么知道它预测得好不好?我们需要一个"错误程度"的数字——机器学习里叫损失(loss),你可以理解成高尔夫得分:越低越好。


  

    问 题
    
正确答案是「好」,模型给「好」79% 的概率,该罚多少分?

    
训练数据里真实的下一个词是「好」。裁判规则很简单:只看模型分给正确答案的那份概率。给得多,轻罚;给得少,重罚;几乎没给,往死里罚。

      用上面的三个按钮逐个核对。顺带一提:大模型新闻里说的"loss 降到 2.0 以下",指的就是这个数的平均值。

import math

def cross_entropy(p_correct):
    return -math.log(p_correct)                # 整个裁判就这一行

for p in [0.79, 0.33, 0.04]:
    print(f"p(正确词)={p}   罚分 L = {cross_entropy(p):.2f}")
# 应得 0.24 / 1.11 / 3.22 —— 和手算验证一致
# 试试把 0.04 改成 0.001,看罚分怎么爆炸

第三课
梯度下降:蒙着眼下山
gradient descent

  
上一课我们有了罚分。模型内部有海量"旋钮"(参数),旋钮位置不同,罚分不同。训练 = 找到让罚分最小的旋钮位置。方法笨得可爱:摸着坡度,一小步一小步往低处挪。


  

    问 题
    
你站在山坡上,大雾,只能感觉脚下的坡度,怎么走到谷底?

    
答案:感受哪边是下坡,朝那个方向迈一步;再感受,再迈。横轴是某个参数 w 的取值,纵轴是罚分 L。"脚下的坡度"有个学名叫梯度,"步子多大"叫学习率 η。

    公 式
    
整个深度学习的发动机,就这一行

    

      

        w←w−η·∇L(w)
      

      
把鼠标移到公式的某一项上试试 →

      
减号是灵魂:梯度指向上坡方向,减去它就是下坡。真实模型里 w 不是一个数,而是几十亿个数,但每一个都执行同样的这一行。顺带一个彩蛋:对 softmax + 交叉熵这套组合,正确词分数的梯度有个漂亮的闭式解 p(正确) − 1——预测越差(p 越小),推力越大,训练自带"错得越狠改得越多"。

    

  


  

    手算验证
    
拿脚下这一步核对

    

      起点 w = −3.40,此处坡度 ∇L ≈ −2.88,取学习率 η = 0.6:

      新 w = −3.40 − 0.6 × (−2.88) = −3.40 + 1.73 = −1.67

      坡度是负的(往右是下坡),减去负数等于往右走——方向自动就对了。点一次上面的「走一步」,对照读数里的算式。

    回到大模型
    
训练 GPT 时,每读一批文本 → 算交叉熵罚分 → 对几百亿个参数各自求坡度(反向传播干的活)→ 全体参数一起执行这行公式。如此重复几百万次,罚分曲线就一路走低。所谓"训练了三个月、烧了几千万美元",烧的就是这一行的重复执行。

  

  

    🐍 用 Python 验证这一课(可选:一键复制,或直接在页内运行)
    

      
lesson3_gradient_descent.py

      
import math

def L(w):                                      # 第三课那座"山"
    return 0.28*(w-2.0)**2 + 0.25*math.sin(1.5*w) + 0.7

def grad(w, h=1e-4):                           # 数值坡度
    return (L(w+h) - L(w-h)) / (2*h)

w, lr = -3.4, 0.6                              # 起点与学习率
for step in range(12):
    w = w - lr * grad(w)                       # 整个深度学习的发动机
    print(f"第{step+1:2d}步   w = {w:7.2f}   罚分 = {L(w):.3f}")
# 把 lr 改成 4.5 再运行一次,亲眼看"发散"长什么样

第四课
自回归:一句话是一串接龙
autoregressive factorization

  
前三课都在说"预测下一个词"这一小步。可模型输出的是整段话——整段话的概率怎么算?答案:接龙,一步一步,把每步概率乘起来。


  

    问 题
    
「今天天气很好」这整句话,模型觉得有多大可能?

    
直接给整句话打分做不到——可能的句子无穷多。但拆成接龙就简单了:先算 P(天气|今天),再算 P(很|今天天气),再算 P(好|今天天气很)……每一步都是第一课的 softmax 输出,乘起来就是整句话的概率。

  


  

    动手玩
    
你来当模型:每一步从候选里挑一个词

    

      

      

        

          
下一个词接什么?(括号里是模型给的概率)

          

          

        

        

          
整句话的概率 = 每一步概率的连乘

          

          

          

        

      

      
试试两条路线:每步都挑概率最高的(这叫贪心解码),再重来一次故意挑低概率的词——看看整句概率差多少倍,以及句子画风的变化。

    

  


  

    公 式
    
把"接龙"写成数学,就是一串连乘

    

      

        P(w1,…,wn)=∏t=1n P(wt | w1…wt−1)
      

      
把鼠标移到公式的某一项上试试 →

      
这一步不是近似,是概率论的恒等式(链式法则)——任何序列的概率都严格等于这串条件概率的乘积。"GPT 只是在预测下一个词"和"GPT 在给整段语言建模",说的是同一件事。

    

  


  

    手算验证
    
沿最高概率路线核对

    

      P(天气|今天)=0.55   P(很|今天天气)=0.60   P(好|今天天气很)=0.62

      P(今天天气很好) = 0.55 × 0.60 × 0.62 ≈ 0.205

      在上面按"天气→很→好"点一遍,看连乘结果是否一致。注意:哪怕每步都很自信,乘几步后总概率也会很小——这正常,因为可能的句子实在太多了。
      
✍️ 轮到你:若三步概率都是 0.5,整句概率 = ?

    

  


  

    回到大模型
    
ChatGPT 逐字蹦出回答的样子,不是加载动画,而是它真的在一个词一个词地执行这个连乘:算概率 → 挑词 → 把挑中的词接回输入 → 再算下一个。训练目标也由此而来:让训练文本里真实句子的连乘概率尽量大——取个对数,恰好就等价于第二课交叉熵之和最小。

  

  

    🐍 用 Python 验证这一课(可选:一键复制,或直接在页内运行)
    

      
lesson4_autoregressive.py

      
p_steps = {"天气 | 今天": 0.55,
           "很 | 今天天气": 0.60,
           "好 | 今天天气很": 0.62}             # 三个条件概率(来自三次 softmax)

total = 1.0
for cond, p in p_steps.items():                # ∏ 连乘,就是一个 for 循环
    total *= p
    print(f"P({cond}) = {p}    累计连乘 = {total:.4f}")

print("整句概率 ≈", round(total, 3))            # 应得 0.205

import math

def softmax(xs):                               # 第一课的老朋友,原封不动
    ex = [math.exp(x) for x in xs]; s = sum(ex)
    return [e / s for e in ex]

words = ["它", "小猫", "老鼠"]
K = {"它": [0.5, 1.0], "小猫": [1.8, 0.6], "老鼠": [0.9, -0.5]}
V = {"它": [0.2, 0.1], "小猫": [1.5, 0.3], "老鼠": [0.4, 1.1]}
q = [2.0, 0.4]                                 # 「它」的查询向量 Q

scores  = [q[0]*K[w][0] + q[1]*K[w][1] for w in words]   # ① Q·K 点积
scaled  = [s / math.sqrt(2) for s in scores]             # ② ÷ √d
weights = softmax(scaled)                                # ③ 变权重
h = [sum(weights[i] * V[words[i]][d] for i in range(3))  # ④ 加权混合 V
     for d in (0, 1)]

print("相关度:", [round(s, 2) for s in scores])   # 「小猫」那格 = 3.84
print("权 重:", [round(w, 2) for w in weights])
print("h =", [round(x, 2) for x in h])           # (1.17, 0.39) ← 第一课折叠框里的 h!

终极彩蛋
三十几行,真的训练一个微型大模型
train a toy model

  
这不是演示,是货真价实的训练:随机初始化参数 → 前向打分 → softmax → 交叉熵罚分 → 手写梯度 → 更新参数,循环 60 轮。五个公式在同一份代码里各就各位(注释里标着"第几课")。看着平均罚分从 1.9 掉到 0.4,然后它会开口说出人生第一句话。

  

    
train_toy_llm.py

    
import math, random
random.seed(0)

# ── 语料:模型即将学会的全部"世界" ─────────────────────────
corpus = "今天 天气 很 好 。 今天 天气 很 冷 。 明天 天气 很 好 。 今天 心情 很 好 。".split()
vocab = sorted(set(corpus))
n = len(vocab)
idx = {w: i for i, w in enumerate(vocab)}

# ── 参数:一张「前一个词 → 各候选词分数」的表,随机初始化 ──
W = [[random.uniform(-0.1, 0.1) for _ in range(n)] for _ in range(n)]
# 真实模型里,「前一个词」会换成 Attention 融合出的向量 h(第五课),
# 打分方式则和第一课折叠框里的 h·W 一模一样。

def softmax(z):                                # ← 第一课
    ex = [math.exp(v) for v in z]; s = sum(ex)
    return [e / s for e in ex]

pairs = list(zip(corpus[:-1], corpus[1:]))     # ← 第四课:整句 = 逐词接龙

lr = 0.5                                       # ← 第三课:学习率 η
for epoch in range(60):
    loss = 0.0
    for prev, nxt in pairs:
        p = softmax(W[idx[prev]])              #    打分 → 概率
        loss += -math.log(p[idx[nxt]])         # ← 第二课:交叉熵
        for j in range(n):                     # ← 第三课:w ← w − η·∇L
            g = p[j] - (1 if j == idx[nxt] else 0)   # 闭式梯度 p−1(彩蛋!)
            W[idx[prev]][j] -= lr * g
    if epoch % 10 == 0 or epoch == 59:
        print(f"第{epoch:2d}轮   平均罚分 = {loss/len(pairs):.3f}")

# ── 训练完毕,让它接龙(推理)──────────────────────────────
w = "今天"
sent = [w]
for _ in range(4):
    p = softmax(W[idx[w]])
    w = max(vocab, key=lambda x: p[idx[x]])    # 贪心:挑概率最高的词
    sent.append(w)
print("模型接龙:", " ".join(sent))

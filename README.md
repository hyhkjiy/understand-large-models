# 看懂大模型:交互式零基础五册

一套**纯静态、零构建、零依赖**的交互式教学网站,带零基础学习者亲手玩懂大模型的完整机制——从五个核心公式,到分词与向量、Transformer 整机、SFT/RLHF 与采样,再到 scaling law 与幻觉的边界。

| 册 | 页面 | 回答的问题 | 内容 |
|---|---|---|---|
| 总目录 | `index.html` | 从哪开始? | 知识地图 · 五册导航 · 三条学习路线 |
| 第一册 | `01-formulas.html` | 模型怎么学会接龙? | Softmax · 交叉熵 · 梯度下降 · 自回归 · Attention |
| 第二册 | `02-tokens.html` | 向量从哪来? | 分词 BPE · Embedding · 位置编码 |
| 第三册 | `03-transformer.html` | 几十层里面是什么? | 多头注意力 · FFN 隐藏层 · 残差/LayerNorm · 反向传播 |
| 第四册 | `04-assistant.html` | 会接龙离 ChatGPT 差什么? | 预训练→SFT→RLHF · 温度/top-p 采样 · 上下文窗口与 KV 缓存 |
| 第五册 | `05-limits.html` | 该信它几分? | Scaling law · 幻觉的机制根源 · 模型≠数据库 |

## 使用

**在线阅读**:https://hyhkjiy.github.io/understand-large-models/

直接用浏览器打开 `index.html` 即可,无需构建、无需服务器(各页通过相对路径互链,建议保持目录结构完整)。

> 页内「▶ 运行 Python」功能基于 Pyodide,首次点击需联网下载引擎(约 10~20 秒);其余全部功能离线可用。

## 设计特点

- **先玩后学**:每课都是"问题 → 动手实验 → 公式逐项点亮 → 手算验证 → 回到大模型"五段式,公式在你自己发现规律之后才登场
- **荧光笔联动**:鼠标悬停公式的任何一项,页面上对应的实验部件会被点亮并给出白话解释
- **串联桥**:课与课、册与册之间有活的联动实验,上一课的输出真实地流进下一课的输入
- **一只玩具模型贯穿五册**:第一册用 30 行代码训练它(查表版)→ 第三册给它装上 embedding + 隐藏层 + 手写反向传播 → 第四册给它装上温度/top-p 骰子 → 第五册逼它产生幻觉(「曹操 的 朋友 是 诗人」)
- **预测门 / 手算题 / 过关检查 / 毕业迁移测验**:先下注再看实验,亲手填数字,换新场景检验是否真的学会
- **页内可运行的 Python**:全系列 23 个代码块,全部只用标准库、可在页内直接运行,也可复制到本地——每一个都经过实际运行验证

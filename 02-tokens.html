第一课

分词:模型眼里没有"字",只有"块"

tokenization

模型不认识文字,只认识编号。第一步,是把一串文字切成一个个「token」——可以是词、半个词,甚至几个字母。切法不是人拍脑袋定的,是从数据里统计出来的。

问 题

「今天天气很好」进入模型前,会变成什么样?

直觉可能是逐字切,或按词典切。真实模型用的是子词(subword)切法:常见的组合当一整块,罕见的拆成小块。这样词表不用无限大,又不会遇到"没见过的词"就卡死。

规 则

词表是怎么造出来的:BPE,三句话说完

从单个字符起步,重复几万次:
统计语料里出现次数最多的相邻一对 → 合并成一个新块,加入词表
把鼠标移到句子的某一部分上试试 →
这个算法叫 BPE(Byte Pair Encoding,字节对编码)。词表大小(比如 10 万)是人定的,但哪些块进词表,完全由数据里的出现频率决定——所以英语里 "the" 是一整块,而生僻词会碎成渣。

lesson1_bpe.py
from collections import Counter

# 语料:五个英文单词(重复代表词频)
words = ["low"]*5 + ["lower"]*2 + ["newest"]*6 + ["widest"]*3
words = [list(w) for w in words]                # 起步:全拆成单字符

for step in range(6):                           # BPE:重复合并 6 次
    pairs = Counter()
    for w in words:                             # ① 统计所有相邻对
        for a, b in zip(w, w[1:]):
            pairs[(a, b)] += 1
    (a, b), cnt = pairs.most_common(1)[0]       # ② 找最常见的一对
    for w in words:                             # ③ 合并成一个新块
        i = 0
        while i < len(w) - 1:
            if w[i] == a and w[i+1] == b: w[i:i+2] = [a+b]
            else: i += 1
    print(f"第{step+1}次合并: {a}+{b} (出现{cnt}次)   newest → {[t for t in words[7]]}")

第二课
Embedding:给每个 token 发一张"性格坐标"
embedding

import math

E = {"猫": (1.2, 4.5), "狗": (1.6, 4.2), "鱼": (0.8, 3.6),
     "苹果": (4.2, 1.2), "香蕉": (4.6, 1.0), "汽车": (7.5, 4.0),
     "男人": (2.6, 6.2), "女人": (3.0, 6.5), "国王": (3.0, 7.5), "女王": (3.4, 7.8)}

def cos(a, b):                                  # 夹角余弦 = 点积 ÷ 两个长度
    dot = a[0]*b[0] + a[1]*b[1]
    return dot / (math.hypot(*a) * math.hypot(*b))

for pair in [("猫","狗"), ("猫","汽车"), ("国王","女王")]:
    print(f"cos({pair[0]}, {pair[1]}) = {cos(E[pair[0]], E[pair[1]]):.3f}")

# 向量算术:国王 − 男人 + 女人 ≈ ?
t = (E["国王"][0]-E["男人"][0]+E["女人"][0], E["国王"][1]-E["男人"][1]+E["女人"][1])
best = max(E, key=lambda w: cos(E[w], t) if w not in ("国王","男人","女人") else -9)
print("国王 − 男人 + 女人 =", t, "→ 最接近:", best)

第三课
位置编码:把"第几个"也写进向量里
positional encoding

  
解决办法依然简单粗暴:给每个位置也造一个向量,直接加到词向量上。同一个词出现在不同位置,进入模型的向量就不一样了——顺序信息由此混入。

import math

def pe(pos, d=8):                              # 位置 pos 的"指纹":d 个数字
    v = []
    for i in range(d // 2):
        angle = pos / (100 ** (2 * i / d))     # 转速逐对变慢(演示用 100,真实用 10000)
        v += [math.sin(angle), math.cos(angle)]
    return v

for pos in range(6):
    print(f"位置{pos}: ", [f"{x:+.2f}" for x in pe(pos)])
# 观察:任何两行都不相同——每个位置一枚独一无二的指纹;
# 且第一列变得快、最后一列变得慢,像秒针和时针。

the input pipeline

  
从一句中文出发,亲手走到"可以送进 Attention 的向量"为止——第一册第五课的起点,就是这段代码的终点。

  

    
input_pipeline.py

    
import math, random
random.seed(0)

# ── STEP 1 分词:贪心找词表里最长的匹配 ──────────────────
vocab = ["今天", "天气", "很好", "很", "好", "明天", "心情"]
def tokenize(text):
    toks, i = [], 0
    while i < len(text):
        for w in sorted(vocab, key=len, reverse=True):
            if text.startswith(w, i): toks.append(w); i += len(w); break
        else: toks.append(text[i]); i += 1       # 词表没有:逐字硬啃
    return toks

tokens = tokenize("今天天气很好")
ids = [vocab.index(t) for t in tokens]
print("token:", tokens, " 编号:", ids)

# ── STEP 2 查 embedding 表(真实模型里这张表是训练出来的)──
d = 4
E = [[round(random.uniform(-1, 1), 2) for _ in range(d)] for _ in vocab]

# ── STEP 3 加位置指纹 ────────────────────────────────────
def pe(pos):
    return [math.sin(pos / 100**(2*i/d)) if j == 0 else math.cos(pos / 100**(2*i/d))
            for i in range(d // 2) for j in (0, 1)]

for pos, (t, i) in enumerate(zip(tokens, ids)):
    x = [round(E[i][k] + pe(pos)[k], 2) for k in range(d)]
    print(f"位置{pos}「{t}」 词向量{E[i]} + 位置指纹 → 实际输入 {x}")
print("↑ 这些向量接下来会乘上参数矩阵得到 Q/K/V——第一册第五课,从这里开始。")

第一课 · 分词

    
token块
模型的最小输入单位:可以是词、半个词、几个字母。计费、上下文窗口的单位都是它。

    
BPE字节对编码
造词表的算法:从单字符起步,反复把"最常相邻的一对"合并成新块。常见内容越合越长。

  

  
第二课 · Embedding

    
Eembedding 表
词表有多少 token 就有多少行,每行一个向量。它是参数,被梯度下降从随机数一路调出来。

    
E[i]查表
方括号 = "取第 i 行"。查表动作本身毫无智能,智能全在表里的数字。

    
A·B点积(第一册的老朋友)
对应位置相乘再相加。结果越大,两个向量越"合拍"。

    
|A|向量长度
从原点到 A 的距离,勾股定理:|(3, 4)| = √(9+16) = 5。

    
cos θ夹角余弦
两个向量夹角的余弦:1 = 同向(意思相近),0 = 垂直(不相干),−1 = 反向。点积 ÷ 两个长度就得到它。

  

  
第三课 · 位置编码

    
pos位置编号
这个 token 是句子里的第几个:0, 1, 2, …

    
sin / cos正弦 / 余弦
三角函数,输入增大时在 −1~1 之间来回摆。这里只当"匀速旋转的指针"用,不必会算。

    
PE(pos)位置向量
位置 pos 的"指纹":一组转速不同的 sin/cos 读数。只看位置,不看词。

    
d维度
向量里数字的个数。演示用 2~8 个,真实模型几千个。
